# Packages excluded from the default XG2010G image.
#
# These packages are built as modules (=m) so their .apk files are available
# later, but the image installer only installs =y packages, so they never end
# up in the default image.  Packages from the helloworld and pushbot feeds are
# republished in the per-build extras repository; the official ImmortalWrt
# distfeeds cover the rest.  A trailing '*' matches a package-name prefix.
# Exact names are also written as "CONFIG_PACKAGE_<name>=m" when absent, so a
# Kconfig default cannot silently re-enable them in the image.
#
# This file is applied by scripts/apply-xg2010g-package-policy.sh and enforced
# by scripts/check-xg2010g-only.sh.  To ship a package in the image itself,
# remove its line here, set it to =y in 2010.config, and rerun the policy
# check.
#
