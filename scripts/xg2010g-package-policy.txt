# Packages excluded from the default XG2010G image.
#
# Users install these on the device when they need them.  Most come from the
# official ImmortalWrt distfeeds and are left unset here, so the firmware build
# does not compile them.  The few the official feeds cannot provide are listed
# in scripts/xg2010g-extras-packages.txt; those are built as modules (=m) and
# published in the per-build extras repository.  A trailing '*' matches a
# package-name prefix.  Exact names are written explicitly even when absent, so
# a Kconfig default cannot silently re-enable them in the image.
#
# This file is applied by scripts/apply-xg2010g-package-policy.sh and enforced
# by scripts/check-xg2010g-only.sh.  To ship a package in the image itself,
# remove its line here, set it to =y in 2010.config, and rerun the policy
# check.
#
