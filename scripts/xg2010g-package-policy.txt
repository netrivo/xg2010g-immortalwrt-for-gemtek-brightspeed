# Packages excluded from the default XG2010G image.
#
# These packages are built as modules (=m): their .apk files are published in
# the per-build extras repository so a device can install them later, but the
# image installer only installs =y packages, so they never end up in the
# default image.  A trailing '*' matches a package-name prefix.  Exact names
# are also written as "CONFIG_PACKAGE_<name>=m" when absent, so a Kconfig
# default cannot silently re-enable them in the image.
#
# Optional-app translations are the exception: they are left unset (=n) rather
# than compiled, because the official LuCI feed already provides them and
# building every language wastes CI time.  The app packages themselves are
# still built as modules for the extras repository.
#
# This file is applied by scripts/apply-xg2010g-package-policy.sh and enforced
# by scripts/check-xg2010g-only.sh.  To ship a package in the image itself,
# remove its line here, set it to =y in 2010.config, and rerun the policy
# check.
#
